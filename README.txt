FRANCIS JR G. VIOLA - PORTFOLIO WEBSITE
=======================================

FILES
  index.html    Home page (about, awards, skills, resume)
  contact.html  Contact page with message form
  style.css     All the custom styling
  script.js     Menu, skill bars and contact form behavior
  contact.php   Form handler (only works on hosting that runs PHP)
  README.txt    This file

HOW TO USE
  1. Unzip everything into one folder.
  2. Open index.html in your browser.
  3. Upload ALL the files to your hosting (keep them in the same folder).

PROFILE PHOTO
  Put a photo named profile.jpg in the same folder as index.html.
  If there is no photo, the initials "FV" are shown instead.

CONTACT FORM
  - On PHP hosting: messages are sent to the email in contact.php
    (change $receiving_email_address if needed).
  - On static hosting (GitHub Pages, Netlify, etc.): the form opens the
    visitor's email app with the message already written.

NOTE
  The site loads Bootstrap and Bootstrap Icons from the internet (CDN),
  so an internet connection is needed to see the full design.
